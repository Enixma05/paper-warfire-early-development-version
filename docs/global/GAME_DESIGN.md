# Game Design Specification (GAME_DESIGN.md)

Dokumen acuan aturan bermain, alur progresi level, dan balancing gameplay.

---

## 1. Aturan Dasar Permainan
- **Objektif Utama:** [Isi objektif kemenangan, misal: Bertahan dan basmi seluruh musuh termasuk Boss]
- **Kondisi Kalah:** Health Point (HP) pemain mencapai 0.
- **Kondisi Menang:** Berhasil mengalahkan Boss di akhir gelombang/area.

## 2. Progresi Permainan (Difficulty Curve)
- **Gelombang / Tahap 1:** Memperkenalkan kontrol dan musuh dasar dengan pola lambat.
- **Gelombang / Tahap 2:** Peningkatan jumlah musuh, munculnya varian musuh berkecepatan tinggi atau proyektil.
- **Tahap Akhir (Boss Battle):** Pertarungan melawan Boss dengan HP tebal dan mekanik serangan area.

## 3. Sistem Skor & Reward
- Skor musuh biasa: +100 poin
- Skor musuh elit / boss: +1000 poin
- Bonus penyelesaian cepat: +Poin berdasarkan sisa waktu
